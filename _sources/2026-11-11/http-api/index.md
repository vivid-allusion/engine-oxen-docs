# Repository API

The Repository API drives all the versioning (VCS) functionality for [oxen.ai](https://oxen.ai) and the open-source [oxen-server](https://docs.oxen.ai/getting-started/oxen-server.md).

It handles managing repositories, branches, and files among other things. Browse
the API endpoints in the sidebar to the left to see what's available. You can
also look at the [File Upload Example](https://docs.oxen.ai/http-api/example.md) to see one possible
workflow for chaining these requests together.
