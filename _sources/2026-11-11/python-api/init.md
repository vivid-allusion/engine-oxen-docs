## init

```python theme={null}
def init(path: str = "./")
```

Initialize a [Repo](https://docs.oxen.ai/python-api/repo.md) at the given path.

**Arguments**:

* `path` - `str`
  The path to initialize the repo at.

**Returns**:

[Repo](https://docs.oxen.ai/python-api/repo.md)
A Repo object that can be used to interact with the repo.
