# GPT 5.6 Luna

> Efficient high-volume model, 1M context

> [card] [Try GPT 5.6 Luna in the Workbench](https://www.oxen.ai/ai/workbench?model=gpt-5-6-luna)
>
> Run this model interactively, tune parameters, and compare outputs.

**Model ID:** `gpt-5-6-luna`

GPT 5.6 Luna is the GPT-5.6 model optimized for cost-sensitive, high-volume workloads. It is the lowest-cost member of the GPT-5.6 family while retaining the family's token efficiency, frontend design quality, and intent understanding.

It supports configurable reasoning effort (none, low, medium, high, xhigh, and max), a pro reasoning mode for quality-first tasks, programmatic tool calling, persisted reasoning across turns, and a broad tool set including functions, web search, file search, and computer use.

| Metric | Value |
| - | - |
| Context Length | 1,050,000 tokens |
| Max Output Tokens | 128,000 tokens |
| Knowledge Cutoff | Feb 16, 2026 |
| Multilingual | Yes |

> [tab] Minimal
>
> ```bash cURL theme={null}
> curl -X POST https://hub.oxen.ai/api/ai/chat/completions \
>   -H "Content-Type: application/json" \
>   -H "Authorization: Bearer $OXEN_API_KEY" \
>   -d '{
>   "model": "gpt-5-6-luna",
>   "messages": [
>     {
>       "role": "user",
>       "content": "Hello, what can you do?"
>     }
>   ]
> }'
> ```
