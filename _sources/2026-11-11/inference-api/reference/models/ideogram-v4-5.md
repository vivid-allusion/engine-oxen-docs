# Ideogram v4.5

> Accurate typography with selectable image quality

> [card] [Try Ideogram v4.5 in the Workbench](https://www.oxen.ai/ai/workbench?model=ideogram-v4-5)
>
> Run this model interactively, tune parameters, and compare outputs.

**Model ID:** `ideogram-v4-5`

Ideogram v4.5 is a text-to-image model focused on accurate typography, posters, logos, and graphic design.

It generates realistic and stylized images with low, medium, and high quality tiers and optional prompt expansion. Output is available at 1K (about 1024 to 1440 pixels on the long edge) or 2K (about 2048 to 2880 pixels) in square, portrait, landscape, 2:1 banner, and 16:10 aspect ratios, and Ideogram prices each image by quality tier only, so both resolutions cost the same.

> > ```bash cURL theme={null}

> > }' | jq -r '.generations[0].generation_id')

> > # Stream the SSE channel, grab the data line that follows a
> > # media_generation_completed event for our id, and pretty-print it.
> > curl -sN -H "Authorization: Bearer $OXEN_API_KEY" https://hub.oxen.ai/api/events \
> >   | awk -v id="$GEN_ID" '
> >     /^event: media_generation_completed$/ { expect=1; next }
> >     /^data: / && expect {
> >       payload = substr($0, 7)
> >       if (index(payload, "\"generation_id\":\"" id "\"")) { print payload; exit }
> >       expect = 0
> >     }
> >   ' | jq .
> > ```
> >
> > ```python Python theme={null}
> > import json
> > import os
> > import requests
> >
> > API_KEY = os.environ["OXEN_API_KEY"]
> > AUTH = {"Authorization": f"Bearer {API_KEY}"}
> >
> > enqueue = requests.post(
> >     "https://hub.oxen.ai/api/ai/queue",
> >     headers={**AUTH, "Content-Type": "application/json"},
> >     json={
> >         "model": "ideogram-v4-5",
> >         "prompt": "<prompt>"
> >     },
> > )
> > enqueue.raise_for_status()
> > generation_id = enqueue.json()["generations"][0]["generation_id"]
> >
> > with requests.get(
> >     "https://hub.oxen.ai/api/events",
> >     headers=AUTH,
> >     stream=True,
> > ) as stream:
> >     event_name = None
> >     for line in stream.iter_lines(decode_unicode=True):
> >         if line.startswith("event: "):
> >             event_name = line.removeprefix("event: ")
> >         elif line.startswith("data: ") and event_name == "media_generation_completed":
> >             payload = json.loads(line.removeprefix("data: "))
> >             if payload.get("generation_id") == generation_id:
> >                 print(payload)
> >                 break
> > ```

## Request parameters

### Required parameters

| Field | Type | Default | Description |
| - | - | - | - |
| `prompt` | `string` | — | Describe the image to generate, including any text and its placement. |

### Optional parameters

| Field | Type | Default | Description |
| - | - | - | - |
| `aspect_ratio` | `string` | `"1:1"` | Aspect Ratio One of: 1:1, 16:9, 9:16, 4:3, 3:4, 3:2, 2:3, 5:4, 4:5, 16:10, 10:16, 2:1, 1:2. |
| `resolution` | `string` | `"1K"` | Resolution One of: 1K, 2K. |
| `image_size` | `object` | — | Pixel dimensions sent to fal, looked up from aspect\_ratio and resolution in the size table below. |
| `quality` | `string` | `"medium"` | Image quality tier. Low costs $0.03, medium $0.06, and high \$0.22 per image, independent of image size. One of: low, medium, high. |
| `enable_prompt_expansion` | `boolean` | `true` | Expand the prompt before generating the image. |
| `seed` | `integer` | — | Random seed. Omit to choose automatically. |
| `sync_mode` | `boolean` | `false` | Return image data directly in the response. |
