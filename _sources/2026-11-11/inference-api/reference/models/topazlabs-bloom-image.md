# Topaz Bloom

> Creative generative image upscaling with prompts

> [card] [Try Topaz Bloom in the Workbench](https://www.oxen.ai/ai/workbench?model=topazlabs-bloom-image)
>
> Run this model interactively, tune parameters, and compare outputs.

**Model ID:** `topazlabs-bloom-image`

Topaz Bloom is a generative image upscaler that invents new, believable detail as it enlarges, similar to Magnific. Steer the added detail with a prompt and adjust how much is invented.

Use it to creatively enhance and upscale images with adjustable creativity, texture, and optional prompt guidance.

> >   case $STATUS in succeeded|failed|cancelled) break;; esac

> > done
> >
> > # Print the result.
> > curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
> >   "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq .

> > }' | jq -r '.generations[0].generation_id')
> >
> > # Stream the SSE channel, grab the data line that follows a
> > # media_generation_completed event for our id, and pretty-print it.
> > curl -sN -H "Authorization: Bearer $OXEN_API_KEY" https://hub.oxen.ai/api/events \
> >   | awk -v id="$GEN_ID" '
> >     /^event: media_generation_completed$/ { expect=1; next }
> >     /^data: / && expect {
> >       payload = substr($0, 7)
> >       if (index(payload, "\"generation_id\":\"" id "\"")) { print payload; exit }
> >       expect = 0
> >     }
> >   ' | jq .
> > ```
> >
> > ```python Python theme={null}
> > import json
> > import os
> > import requests
> >
> > API_KEY = os.environ["OXEN_API_KEY"]
> > AUTH = {"Authorization": f"Bearer {API_KEY}"}
> >
> > enqueue = requests.post(
> >     "https://hub.oxen.ai/api/ai/queue",
> >     headers={**AUTH, "Content-Type": "application/json"},
> >     json={
> >         "model": "topazlabs-bloom-image",
> >         "input_image": "https://hub.oxen.ai/api/repos/elau/assets/file/main/bloxy/bloxy_cropped_512x512.png"
> >     },
> > )
> > enqueue.raise_for_status()
> > generation_id = enqueue.json()["generations"][0]["generation_id"]
> >
> > with requests.get(
> >     "https://hub.oxen.ai/api/events",
> >     headers=AUTH,
> >     stream=True,
> > ) as stream:
> >     event_name = None
> >     for line in stream.iter_lines(decode_unicode=True):
> >         if line.startswith("event: "):
> >             event_name = line.removeprefix("event: ")
> >         elif line.startswith("data: ") and event_name == "media_generation_completed":
> >             payload = json.loads(line.removeprefix("data: "))
> >             if payload.get("generation_id") == generation_id:
> >                 print(payload)
> >                 break
> > ```

## Request parameters

### Required parameters

| Field | Type | Default | Description |
| - | - | - | - |
| `input_image` | `string` | — | Image to enhance and upscale (URL or file path). jpeg, png, gif, or webp. Format: uri. |

### Optional parameters

| Field | Type | Default | Description |
| - | - | - | - |
| `prompt` | `string` | `""` | Optional prompt to guide the added detail (max 1024 characters). |
| `creativity` | `integer` | `3` | How much new creative detail to add (1 faithful, 9 most creative). Range: 1 – 9. |
| `enhancement_strength` | `string` | `"medium"` | Overall enhancement strength. One of: low, medium, high. |
| `texture` | `integer` | `3` | Texture enhancement strength (1-5). Range: 1 – 5. |
| `sharpen` | `number` | `0` | Sharpening amount (0.0-1.0). Range: 0 – 1. |
| `denoise` | `number` | `0` | Noise reduction amount (0.0-1.0). Range: 0 – 1. |
