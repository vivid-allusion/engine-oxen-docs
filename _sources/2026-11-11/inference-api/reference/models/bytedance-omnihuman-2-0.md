# OmniHuman 2.0

> Audio-driven talking and singing avatars

> [card] [Try OmniHuman 2.0 in the Workbench](https://www.oxen.ai/ai/workbench?model=bytedance-omnihuman-2-0)
>
> Run this model interactively, tune parameters, and compare outputs.

**Model ID:** `bytedance-omnihuman-2-0`

OmniHuman 2.0 is ByteDance's audio-driven human animation model: it turns a single image and a voice track into a video of the subject speaking or singing, with lip sync, facial expression, and body gesture that follow the rhythm and meaning of the audio.

It works from any framing, from close-up portraits to full-body shots, and on photographs as well as illustrated, 3D-rendered, and non-human characters. Images with several people produce multi-person scenes. An optional text prompt directs camera movement, specific actions, and added elements that are not in the source image; prompts can be written in English, Chinese, Japanese, Korean, Mexican Spanish, or Indonesian.

The video runs as long as the audio, from 4 seconds up to 5 minutes, and is billed per second of output. Output is 720p-class with its aspect ratio following the input image. Audio must be WAV or MP3 under 15 MB; the image must be between 300 and 6000 pixels per side with an aspect ratio between 0.4 and 2.5.

| Metric | Value |
| - | - |
| Parameter Count | Unknown |
| Mixture of Experts | Unknown |
| Context Length | 4 to 300 seconds of audio |
| Multilingual | Yes (prompts in 6 languages; speech in any language) |
| Quantized\* | Unknown |

\*Quantization refers to whether the served weights are reduced-precision.

> >   STATUS=$(curl -s -H "Authorization: Bearer $OXEN_API_KEY" \

> > done
> >
> > # Print the result.

> >   "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq .

> >       payload = substr($0, 7)

> >     }
> >   ' | jq .

> > import json
> > import os

> > enqueue = requests.post(
> >     "https://hub.oxen.ai/api/ai/queue",

> >     },
> > )
> > enqueue.raise_for_status()
> > generation_id = enqueue.json()["generations"][0]["generation_id"]
> >
> > with requests.get(
> >     "https://hub.oxen.ai/api/events",
> >     headers=AUTH,
> >     stream=True,
> > ) as stream:
> >     event_name = None
> >     for line in stream.iter_lines(decode_unicode=True):
> >         if line.startswith("event: "):
> >             event_name = line.removeprefix("event: ")
> >         elif line.startswith("data: ") and event_name == "media_generation_completed":
> >             payload = json.loads(line.removeprefix("data: "))
> >             if payload.get("generation_id") == generation_id:
> >                 print(payload)
> >                 break
> > ```
