# Seedream 5.0 Pro

> Precise image generation and editing

> [card] [Try Seedream 5.0 Pro in the Workbench](https://www.oxen.ai/ai/workbench?model=bytedance-seedream-5-pro)
>
> Run this model interactively, tune parameters, and compare outputs.

**Model ID:** `bytedance-seedream-5-pro`

ByteDance Seedream 5.0 Pro is an image generation and editing model built for precise, region-level control and professional design work. It generates images from a text prompt and performs single-image and multi-reference editing (recolor, material swap, object replacement, multi-image fusion), with native multilingual text rendering across more than 10 languages and strong layout reasoning for text-dense compositions.

Each request returns a single image at up to 2K (2048x2048) across a range of aspect ratios, and up to 10 reference images can guide an edit.

> > [tab] Minimal
> >
> > ```bash cURL theme={null}
> > # Enqueue, capture the generation id.
> > GEN_ID=$(curl -s -X POST https://hub.oxen.ai/api/ai/queue \

> > # Poll until the generation reaches a terminal status.
> > while true; do
> >   STATUS=$(curl -s -H "Authorization: Bearer $OXEN_API_KEY" \

> >   echo "Status: $STATUS"
> >   case $STATUS in succeeded|failed|cancelled) break;; esac
> >   sleep 5
> > done
> >
> > # Print the result.
> > curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
> >   "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq .
> > ```

> >         break
> >     time.sleep(5)
> >
> > if data["status"] == "succeeded":
> >     print(f"Result: {data['result_url']}")

> > # Stream the SSE channel, grab the data line that follows a
> > # media_generation_completed event for our id, and pretty-print it.
> > curl -sN -H "Authorization: Bearer $OXEN_API_KEY" https://hub.oxen.ai/api/events \
> >   | awk -v id="$GEN_ID" '
> >     /^event: media_generation_completed$/ { expect=1; next }
> >     /^data: / && expect {
> >       payload = substr($0, 7)
> >       if (index(payload, "\"generation_id\":\"" id "\"")) { print payload; exit }
> >       expect = 0
> >     }
> >   ' | jq .
> > ```
> >
> > ```python Python theme={null}
> > import json
> > import os
> > import requests
> >
> > API_KEY = os.environ["OXEN_API_KEY"]
> > AUTH = {"Authorization": f"Bearer {API_KEY}"}
> >
> > enqueue = requests.post(
> >     "https://hub.oxen.ai/api/ai/queue",
> >     headers={**AUTH, "Content-Type": "application/json"},
> >     json={
> >         "model": "bytedance-seedream-5-pro",
> >         "prompt": "<prompt>"
> >     },
> > )
> > enqueue.raise_for_status()
> > generation_id = enqueue.json()["generations"][0]["generation_id"]
> >
> > with requests.get(
> >     "https://hub.oxen.ai/api/events",
> >     headers=AUTH,
> >     stream=True,
> > ) as stream:
> >     event_name = None
> >     for line in stream.iter_lines(decode_unicode=True):
> >         if line.startswith("event: "):
> >             event_name = line.removeprefix("event: ")
> >         elif line.startswith("data: ") and event_name == "media_generation_completed":
> >             payload = json.loads(line.removeprefix("data: "))
> >             if payload.get("generation_id") == generation_id:
> >                 print(payload)
> >                 break
> > ```

## Request parameters

### Required parameters

| Field | Type | Default | Description |
| - | - | - | - |
| `prompt` | `string` | — | Text prompt for image generation, or the instruction for editing the input images. Use @Image1, @Image2, etc. to reference the input images. |

### Optional parameters

| Field | Type | Default | Description |
| - | - | - | - |
| `input_image` | `array<string>` | — | Optional reference image URLs for image-to-image editing. Provide one image for single-image editing or multiple for multi-reference fusion; reference them in the prompt as @Image1, @Image2, etc. Up to 10 images. |
| `aspect_ratio` | `string` | `"1:1"` | Aspect Ratio One of: 1:1, 4:3, 3:4, 16:9, 9:16, 3:2, 2:3, 21:9. |
| `image_size` | `object` | — | Pixel dimensions sent to Seedream, looked up from aspect\_ratio and size in the size table below. |
| `size` | `string` | `"2K"` | Resolution level. Combined with the aspect ratio to set the output dimensions. One of: 1K, 2K. |
| `output_format` | `string` | `"png"` | Output image format. One of: png, jpeg. |
| `watermark` | `boolean` | `false` | Whether to add an 'AI generated' watermark. |
