# Qwen Image 2.0 Pro

> Text-to-image and editing, 2K, strong typography

> [card] [Try Qwen Image 2.0 Pro in the Workbench](https://www.oxen.ai/ai/workbench?model=qwen-image-2-pro)
>
> Run this model interactively, tune parameters, and compare outputs.

**Model ID:** `qwen-image-2-pro`

Qwen Image 2.0 Pro is the Pro tier of Alibaba's Qwen Image 2.0 series, a closed model for text-to-image generation and instruction-based image editing with strong text rendering, realistic texture, and close prompt adherence.

It renders any size from 512x512 up to 2048x2048 total pixels, with 2K output by default, and handles professional typography for layouts such as slides, infographics, posters, calendars, charts, and comics in both Chinese and English. For editing it takes up to three input images in one request, which covers single-image edits, style transfer, and multi-image composition, and it can return up to six candidates per call.

Prompts are limited to 1,300 tokens and weights are not published.

| Metric | Value |
| - | - |
| Context Length | 1,300 tokens |
| Max Resolution | 2048x2048 (2K) |
| Multilingual | Yes (Chinese, English) |

> >   sleep 5
> > done
> >
> > # Print the result.
> > curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
> >   "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq .

## Request parameters

### Required parameters

| Field | Type | Default | Description |
| - | - | - | - |
| `prompt` | `string` | — | Text prompt describing the image to generate, or the edit to apply. Use @Image1, @Image2, etc. to reference the input images. |

### Optional parameters

| Field | Type | Default | Description |
| - | - | - | - |
| `input_image` | `array<string>` | — | Optional input images to edit or combine. The output keeps the aspect ratio of the last image unless an aspect ratio is chosen. Reference them in the prompt as @Image1, @Image2, etc. Up to 3 images. |
| `aspect_ratio` | `string` | `"16:9"` | Aspect Ratio One of: auto, 16:9, 9:16, 1:1, 4:3, 3:4. |
| `resolution` | `string` | `"2K"` | Resolution One of: 1K, 2K. |
| `num_images` | `integer` | `1` | Number of images to generate, 1 to 6. Only the first is returned; all are billed. Range: 1 – 6. |
| `enable_prompt_expansion` | `boolean` | `true` | Let the model rewrite the prompt with more detail before rendering. Turn off for tighter control over the wording. |
| `negative_prompt` | `string` | — | What to keep out of the image. Up to 500 characters. |
| `seed` | `integer` | — | Seed for reproducible generation, 0 to 2147483647. Results can still vary between runs. |
| `watermark` | `boolean` | `false` | Add an AI-generated watermark in the bottom-right corner. |
